# Vignesh — Portfolio

A responsive, single-page portfolio with a playful original sidekick, an original synthesized bell-like hello, and interactive project demos. It uses plain HTML, CSS, and JavaScript; no install or build step is needed.

## Run it

Open `index.html` in a browser, or serve this folder with any static web server.

## Personalize it

- Add your role, location, about text, project names/descriptions, and email address in `index.html`.
- Adjust colors, layout, and the sidekick in `styles.css`.
- Change or disable the synthesized hello sound in `script.js`. Sound starts only after a user click/tap, and the sound toggle can turn it off.
- The Number Guessing Game and Java Banking System cards open playable demos. The banking demo uses Indian rupees, is local-only, resets to its sample balance each time, and does not connect to a real bank or move real money.

The sidekick and background robot buddies are original; no character artwork or recorded character audio is included.
